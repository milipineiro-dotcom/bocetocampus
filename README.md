# Campus Docentes Brown · versión iPhone/Apple

Subí `index.html` y la carpeta `pdfs/` al mismo nivel del repositorio.

Estructura:
- index.html
- pdfs/
  - procedimiento.pdf
  - el_concurso_paso_a_paso.pdf
  - propuesta_pedagogica.pdf
  - clase_publica_entrevista.pdf
  - regimen_academico.pdf
  - cuaderno_de_trabajo.pdf

La interfaz usa una estética inspirada en Apple: tipografía de sistema, tarjetas translúcidas, bordes suaves, mucho espacio y diseño responsive.

Activá GitHub Pages desde Settings > Pages.
